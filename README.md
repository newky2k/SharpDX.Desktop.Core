# SharpDX.Desktop.Core

This project provides a .NET 6.0, .NET 8.0, .NET 10.0, .NET 11.0 AND .NET Framework 4.6.1 compatible version of the SharpDX.Desktop [SharpDX.Desktop](https://www.nuget.org/packages/SharpDX.Desktop/). It also provides a .Net framework version of the library using multi-targeting.

Building the library requires the .NET 10 and .NET 11 SDKs (Visual Studio 2026 or the dotnet CLI).

The original library can be found here: https://github.com/sharpdx/SharpDX.
